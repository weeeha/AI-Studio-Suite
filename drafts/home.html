AI Studio Suite

Six filmmaking tools, one address. Story to shot to motion reference.

  1. 1

    Cork Board

    Index cards, acts and arcs on a planning wall.

    Open
  2. 2

    ScriptBreak

    Import a script; get scenes, elements, shot lists and prompt packs.

    Open
  3. 3

    Slate

    Plan shots and coverage, keep continuity, compile prompts per generator.

    Desktop only for nowFork on GitHub for Slate
  4. 4

    Storyboard Reference Studio

    Turn reference images and video into storyboard stills and prompts.

    Desktop only for nowFork on GitHub for Storyboard Reference Studio
  5. 5

    Motion Previs Studio

    Pull pose, depth and camera motion out of a reference clip.

    Desktop only for nowFork on GitHub for Motion Previs Studio
  6. 6

    Blockout

    Stage grey-box scenes, block camera and cast, export motion-reference packages.

    Desktop only for nowFork on GitHub for Blockout

Tools by Sam Wasserman, Wasserman Productions (wassermanproductions.com), Apache-2.0. If they help you, support the author at ko-fi.com/samwasserman.
